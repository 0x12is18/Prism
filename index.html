Google Photos Setup

Prism uses Google's official Photos API — your photos never touch any third-party server. You just need a free OAuth Client ID from Google Cloud.

1

Create a Google Cloud Project

Go to console.cloud.google.com → click the project dropdown → New Project. Name it anything.

2

Enable Photos Library API

In your project go to APIs & Services → Library → search Photos Library API → click Enable.

3

Configure OAuth Consent Screen

Go to APIs & Services → OAuth consent screen. Choose External, fill in App Name (e.g. "Prism"), add your email, save.

4

Create OAuth Credentials

  • Go to Credentials → Create Credentials → OAuth client ID
  • Type: Web application
  • Authorized JS origins:
  • Authorized redirect URIs:
  • Hit Create → copy the Client ID
